# GAME DESIGN — EKIDEN MANAGER (Alpha v0.4)

## 1. Pillars / プレイヤー体験

- 大学駅伝の監督として、全国優勝まで**数年単位**で選手・資金・戦術を積み上げる。
- 「北稜大学」は架空の常勝校。奇抜な敵、異能力、怪獣、超自然的効果は禁止。
- プレイヤーはスタッツ劣勢でも、練習の当たり・当日の好調・4年生の意地・CPUの失速でごくまれに勝てる。結果抽選で強制優勝させない。
- 練習を一律倍増させるアイテムは魔法ではなく、部費を使った**強化合宿**として表現し、疲労のトレードオフを伴わせる。
- 2Dダッシュボードで区間順位・タイム・実況を見せる。リアルな3D走行モデルは作らない。
- CPU対戦中心。オフライン完結。対人通信はアルファには入れない。

## 2. Core loop

1. **新年度開始** — 大学の部費配分・卒業生からの支援を受け、運営固定費を現金で支払う。
2. **週次練習×12** — 育成項目と強度を選び、能力値上昇・疲労・士気・ランダム好調を計算。
3. **支援購入** — 旅行・練習予備費を残して合宿・測定・栄養回復・雨天装備に投資。
4. **5区間の出走選手を確定** — 5人の重複なし。
5. **全国駅伝×5区間** — 8校で競争。各区間を3チェックポイントに分割して、温存・標準・攻めを指示。残体力の消費と失速を計算し、計15回の地点順位を更新。
6. **年度決算** — 台帳を締め、年間収支・期末残高・大会結果を保存。4年生卒業→新入生加入→翌年度。

## 2.1 Optional club-fund prediction and victory deadline

- 本作は8年間で全国優勝を目指す。最終年度まで一度も優勝できない場合GAME OVER。
- 架空の順位予想ボードは大学選手の能力から独立した乱数で512回試算し、予想確率・倍率を決める。
- 年1回2万〜40万円の部費支出。的中した場合のみ購入額×倍率の合計払戻しを部費へ計上。遠征費の最低残高を確保。
- 完全オフラインで現金・金銭的価値への交換なし。販売先のギャンブル関連制約が未審査のため商用版はHOLD。

## 3. Five abilities and dynamic runner state

| Stat | Meaning |
|---|---|
| speed | 平地・高速域を走る能力 |
| stamina | 長距離ペース維持、攻めの失速判定 |
| hill | 登坂やコース適性 |
| grit | 厳しい局面での粘り |
| recovery | 疲労回復と練習効率 |
| fatigue | 現在の蓄積疲労（能力と別管理） |
| morale | 当日の心理面に影響、能力と別管理 |
| senior clutch | 4年生がレースで粘る確率的な追加要因 |

区間の走行タイムは各能力、地形、疲労、士気、雨天、戦術、個人固有ノイズの合成から決まる。
**ノイズは連続値**で、順位をそのまま抽選したり、敵校にハンデを直接与えて勝敗を決めたりしない。

## 4. AI difficulty and balancing

**原則:** 強豪が強いのは素の能力と安定した走力のためであり、内部で勝敗を固定しない。

- 北稜大学は他大学より高い基本能力を持つが、当日の好不調・失速に遭う可能性がある。
- 自チームの成長は選手の育成と新入生の質の改善の2経路。ベテランの卒業でいったん弱くなることもある。
- CPU7大学はそれぞれ10人の選手名簿を管理。毎週の練習、大学ごとの戦術傾向、翌年の卒業・新入部員、年間の収支を持ち、強さもゆっくり変動する。
- AIが**強すぎて序盤に勝てない**ことと、**後年に勝てるようになること**の双方をモンテカルロで検証。
- Alphaの検証方針：1,200個の乱数シード × 7シーズン、毎年1合宿（資金が許せば）、4能力均等育成、温存→標準→終盤スパート。
- 2026-10-08現在の測定：1年目優勝1.67%、5年目22.92%、6年目47.00%、7年目63.75%（通常育成＋序盤温存/終盤スパート）。これは条件付き実験であり、ゲーム全体の一般的勝率ではない。
- 簡単すぎる/難しすぎる場合、能力差、練習伸長、学年入れ替え、CPU基礎値、ノイズを**独立に**調整する。

## 5. Club finance

**現金主義の部費台帳**（ゲーム設計用の仮モデル。実在の大学会計ではない）。

- 大学配分、OB・OG会支援（任意の大会後追加支援）を「収入」へ計上。
- 年間運営費は年初に支払う。大会遠征費、トレーニング、合宿などは利用・購入時に支払う。
- 支出はマイナスの台帳行として残し、予算残高は全取引の総和と一致。
- 年度末の収入、費用、収支差額、期首と期末の現金残高を確定し、次年度へ繰越し。
- **予算のソフトロック禁止:** 年間残りの最低練習費と大会遠征費を確保できない購入を禁止する。
- 大会の活躍に対する卒業生の追加支援は活動費の寄付とし、競技賞金として扱わない。

## 7. Next milestone (Beta candidate)

1. 2Dのコース図・体力ゲージは実装済み。残る課題：戦術の詳しい説明、CPUのペース戦略とラップをUIで比較する機能。
2. 区間途中の戦術変更は15チェックポイント制で実装済み。残る課題：タスキ受け渡し演出と2Dアニメーション。
3. CPU大学は個々の年間育成・会計・世代交代に対応。次はスカウト費・戦術的な差と収支の長期バランスを改善。年間の意思決定にトレードオフを増やす。移動費、合宿、施設更新、スカウト活動、寄付収入の変動。
4. プレイヤーが勝てない/簡単すぎる戦術を検出する自動対戦による分析を拡充。
5. Windowsの未署名配布バイナリ化はGitHub Actionsで成功済み。残る課題：デスクトップ人間受け入れ試験・DPI・署名・商用素材の権利確認。

## 8. Safety and content boundaries

- レースでのスピードや強度は**架空のゲーム式**。現実のスポーツ生理・実在選手の予測モデルではない。
- 実在校の商標や公式大会ロゴを無断利用しない。大学・選手名はオリジナル。
- データの送信・分析トラッキング・アカウント登録は行わない。
