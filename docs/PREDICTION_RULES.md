# 8年間の全国制覇・架空順位予想（開発Alpha v0.4）

この機能は**完全オフラインのゲーム内シミュレーション**です。架空の大学・部費・競技大会を扱います。賭金に見立てた部費はゲーム内の数値であり、実際の金銭・決済・現金化・換金・売買・外部サービスへの移転はできません。**Lemon Squeezyなどの販売先で販売できることを保証しません。** 販売前に対象プラットフォームへ書面で確認し、必要なら機能を削除・変更します。

## 8年間のゴール

- 創部から**8シーズン以内に1回でも全国大学駅伝で総合優勝**することが目標。
- 初年度から運や戦術による優勝は可能。能力値が勝敗を確定しない。
- 8年目の大会終了後まで一度も優勝できなければ **GAME OVER**。
- 途中で優勝した後も、8年目までの残りシーズンを遊べる。最後は優勝実績の有無で「達成 / 未達成」を判定。
- 年ごとの決算と選手名簿・卒業生・ライバル戦力は保存し続ける。新しい監督生活を選択するとリセット。

## 順位予想の遊び方

1. 12週の練習を終え、遠征費を確保する。
2. オッズ表から**8大学のうち1校・1〜8位のうち1つ**を選ぶ。
3. 予想に使う部費 **2万〜40万円（画面でも1万円刻みの全39通り、1シーズン1回）** を選択。
4. 購入時に部費から差し引き、台帳に「架空順位予想支出」として記帳。最低48万円の大会遠征費を残せない購入は禁止。
5. 大会終了後、実際の着順と一致した場合のみ、**購入額×確定倍率**（購入額を含む合計払戻し）を部費に計上。不的中なら払戻しなし。
6. オッズは購入時の値で確定し、後から変更できない。
   - 購入後は同じ大会の自チーム区間配置も固定される。予想せず大会へ進む場合は大会直前まで変更可能。
7. 予想に参加しなくても通常の育成・駅伝ゲームは遊べる。

## オッズの計算

- 現在の8校・各5選手のスピード・持久力・登坂・精神力・疲労を使用。**512件のレース展開パッケージ（晴384件・雨128件）**を疑似乱数で再現し、実際の大会と同じエンジンで試算する。天候・当日の調子・突発的失速・CPU戦術・4年生の粘りを含む。
- 各校の順位別の試算頻度から推定確率を出し、確率の95%モンテカルロ標本誤差区間（Wilson法）もUIに表示する。これはモデル自体の正確性を保証する区間ではない。
- 購入時の倍率は平滑化確率 `(着順回数+1)/(512+8)` に対して `0.78/確率` を基礎に計算、**1.0〜16.0倍**に制限。極端な本命は1.0倍（的中しても差引利益ゼロ）、大穴も16倍が上限。
- オッズは**同じ選手・戦術・装備条件ならキャッシュを再利用**し、大学・出走選手や能力が変わったら新たな512試算を行う。元のセーブデータや本番レースの乱数には手を加えない。
- **推定確率は実際の確率を保証しない。** 本番は天候、調子、体力、CPU戦術、プレイヤーの作戦、最終学年の意地とランダムな失速が絡む。
- **オッズ計算はレース本体の乱数状態を変更しない**ため、予想の購入によってレース結果は変更されない。
- 予想オッズは公平な公式賭博市場のオッズや資産価値を表すものではない。

## 商用販売のゲート

- 日本での販売・想定される年齢レーティングおよび配信先のコンテンツ規則を確認。
- 特にLemon Squeezyではギャンブル関連商品の禁止ルールがあるため、**順位予想機能を含む販売版の許可を事前に得るまではHOLD**。
- 利用規約上、現金化、勝ち金の実物景品交換、第三者送金、実在の競馬・駅伝への賭け、オンラインの対人現金予想を行わない。

## バランス上の注意

- 順位予想はゲームのリスク・リターン選択肢であり、必須ではない。部費は架空の大学運営資金。リアルの部費を賭けることを推奨しない。
- 試算は毎年の選手の実力と区間配置に応じて変化し、当日の実際の作戦によって的中頻度は変わる。表示確率・倍率は推定値であり当選保証はない。
- 購入後の取消し不可、外れた場合の掛金全損をゲーム内の説明に明示する。
