# EKIDEN MANAGER — 合同練習・時間進行の実装仕様
2026-10-19 / 開発ブランチ `feature/paid-joint-practice-20261019`

## 目的
「練習試合」を作らず、他チームとの合同練習を自主的に有料参加できる仕組み。対戦結果や練習試合の勝敗は発生しない。
既存の12週→5区間・15地点→年度決算→翌年度の流れ、既存の強化合宿・招待割引、セーブIDは変更しない。

## 進行
- 第1〜4週：基礎育成。能力と疲労を確認して週次練習
- 第5〜8週：強化・区間候補の検討。必要なら合同練習で補強
- 第9〜12週：疲労回復と大会準備。12回の週次練習後に正式な大会
- 大会：5区間 × 各3地点で戦術を判断。試合中に合同練習はできない
- 大会後：年度決算、選手の進級・卒業、後輩の加入。前年度の合同練習履歴は保持

## 新しい有料合同練習
- 参加費 ¥220,000 / 1回。部費台帳に「合同練習費」1行だけ記録
- 出走予定の5人が参加。実行前に5人それぞれへ `speed/stamina/hill/grit/recovery` の項目を指定
- 1人につき選択技能+1.0ポイント、5人で合計5.0ポイント。能力上限は99（上限時は増分が減少）
- 参加者ごとに疲労+5、士気+2（最大100）
- 週は進行しない。第1週の練習終了後から第11週まで参加可能
- 同週1回以内、同年度2回以内。対象5人の重複/未登録選手/不正技能指定は拒否
- 部費は残り12週の最低練習費と遠征費の引当を維持できる場合だけ支払える。合宿や栄養支援とは別機能
- 他大学名を表示しない「他チームとの合同練習」。実名大学・大会のライセンス素材を使わない
- 抽選式の既存「合同合宿への招待枠」は既存機能として維持。新しい合同練習には抽選・参加資格・勝敗はない
- 旧セーブに `jointTraining` がなくても `validate` と `migrateSave` で読込可能。年度ごとの参加履歴を保持する

画面のクリック、実機表示、セーブ書出し/再読込、MSIX/WACKが未確認の場合は販売HOLD。
