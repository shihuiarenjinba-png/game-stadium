# Changelog / 変更履歴

開発・検証用の記録です。正式な有料リリース履歴ではありません。

## 0.3.0 — 2026-10-08（開発Alpha）

- CPUの大学7校に各10名の選手名簿、年度ごとの練習・学年・卒業・新入部員と成績を追加
- 大学ごとの持久・登坂・速度など育成傾向と区間配置を導入
- 敵大学の年度予算（収入・支出・期首残高・期末残高）を反映し、矛盾する保存データは拒否
- 「ライバル大学の偵察」画面に主力選手・能力・学年・大学予算・昨年度順位を表示
- 選手の距離別自己ベスト、卒業生名鑑、歴代大会の8大学全順位・タイムを保存
- 初見の操作を説明する「監督手帳」を追加
- 難易度を再調整。1,200シード・7年の固定ポリシー試算で、通常育成は初年度1.67%、5年目22.92%、6年目47.00%の優勝率
- Windows UI自動テストにコンパクト画面、125%ズーム、ワイド画面のスクリーンショットを追加（実OSのDPIの人間確認は未完）
- 開発用バイナリのWindows CI、Node回帰テストを継続。旧セーブは起動時に移行処理を実行
