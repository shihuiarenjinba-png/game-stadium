## v0.7.0 — メンタルと日本語・英語UI（開発Alpha）

**大会中の心理変動**
- 選手の基礎精神力 `stats.grit` と、独立した心理特性 `traits.consistency`（安定性）・`traits.stage`（本番耐性）を区別
- 各区間の開始時に、抽選による「大舞台の緊張で失速」「ゾーンに入る」「通常の集中状態」を判定。高い基礎精神力があっても、本番耐性が低い場合には失速しうる
- 心理状態・ペース補正を大会のチェックポイント履歴に記録。CPU選手にも同じ心理モデルを使用
- 既存セーブの心理特性には決定的なデフォルト値を補い、保存中の乱数状態を変えずに移行
- 係数と確率は娯楽用の架空のバランス設計であり、実際のアスリートや医学的評価には使えない

**同一リポジトリでのJP/EN言語切り替え**
- Windows版は1つのEXEに日本語・英語のUI訳を同梱（初期値＝日本語）。画面右上の「日本語 / English」で変更できる
- 言語設定 `ekiden-manager-language` と進行状況 `ekiden-manager-v1` は別に保存。言語を変えても選手・乱数・成績・所持金は変わらない
- 画面見出し、スカウト、選手能力、給水、メンタル、練習、試合UI、ショップなどの主要文言を英訳。**架空の人名、学校名、動的な会計・イベント文、古いセーブに含まれる叙述などは日本語のまま残り得る**。英語版は翻訳監査が残るベータ品質
- WindowsのUIスモークで画面の両言語とセーブ不変性をチェック。正式なストア公開と商用販売は手動UI/DPI・翻訳完全性、権利、署名、ストア規約確認までHOLD
- 紹介画像は外部のサッカー・競馬・他タイトル画像を使用せず、**実際の駅伝管理ゲームから撮影したスクリーンショット**を優先

## Alpha v0.6.0 — 全国高校スカウト制度

- 全国**40の架空高等学校**に、毎年高校3年生の候補者が2〜3名ずつ分散（合計80〜120名程度）。
- 高校の在籍候補者・突出した能力・天才候補の学校は**訪問前には表示されない**。視察先は40校から選び、1校あたり**18万円**を部費として使う。
- 1年間の訪問上限は3校、発見した候補への**入部打診は最大3名**。見つけた選手が必ず入部するわけではなく、入部辞退の可能性もある。
- 調査した高校の卒業生が翌年度の新入生として加入した場合、元の高校と実力を引き継ぐ。スカウトをしなくても従来どおり一般入部は続く。
- 候補者の能力は視察時の概算値として見える。いわゆる「スーパー1年生」がどの高校にいるかは、ゲーム開始時点で知らされない。
- 高校名はゲーム用の架空名称。実在の学校に対応する選手、スカウト実績や出身地ではない。
