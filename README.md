- 選手の基礎精神力 `stats.grit` と、独立した心理特性 `traits.consistency`（安定性）・`traits.stage`（本番耐性）を区別

- 画面見出し、スカウト、選手能力、給水、メンタル、練習、試合UI、ショップなどの主要文言を英訳。**架空の人名、学校名、動的な会計・イベント文、古いセーブに含まれる叙述などは日本語のまま残り得る**。英語版は翻訳監査が残るベータ品質

# EKIDEN MANAGER — 栄光への襷

**ローカル・オフラインで動作する、大学駅伝育成＆部費経営シミュレーション（Alpha v0.4）**

架空の大学駅伝チームの監督として、選手の5つの能力を育てながら、区間配置とレース戦略、年間の部費を管理します。CPU7大学との5区間・50kmレース（各区間を3分割した全15チェックポイント）で、絶対王者「北稜大学」の連覇を止めることが目標です。運と精神面も結果に影響するため、能力値の大小だけでは順位が決まりません。

> **開発途中の試作版です。** Windows向けの未署名テストEXEは生成できますが、販売用決済・ライセンス認証、コード署名、外部テスターによる品質保証は未完了です。大学・大会・選手・資金は架空の設定です。

## 遊び方（ネット回線・サーバー不要）

1. リポジトリをZIPで取得して展開する。
2. Windowsで `index.html` をダブルクリックしてブラウザー（Edge/Chrome等）で開く。
3. 「区間配置」で5人を選び、「週間トレーニング」で12週分の育成を進める。
   - スカウト活動（1回18万円・年3回まで）に投資すると、翌年度の新入生の能力が上がります。
4. 部費を使い、強化合宿や栄養・リカバリー支援などを購入する。
5. 「大会を開始する」→ 1区間3地点×5区間の計15チェックポイントでペース（温存・標準・攻め）を指示 → 結果を確認する。残体力が少ない状態で攻めすぎると失速します。
6. 「年度決算を確定して次年度へ」で、卒業・新入部員加入の次年度に進む。

**セーブ:** ブラウザーの `localStorage` に自動保存を試みます。ローカルファイル（`file://`）のストレージ挙動はブラウザーによって異なるため、必ず画面下の「セーブ書き出し」でJSONバックアップを保管してください。「セーブ読込」で続きを再開できます。

## 競馬中継風のレース画面と架空順位予想（v0.4）

- 8大学が走る様子を、**競馬中継風の楕円トラック、大学番号、実況、順位表、進行バー**で表現（描画は模式図であり、3Dの走行アニメーションではありません）。
- 12週の育成後、大学と「何位に入るか」を選択できます。大学別の能力値から512回の独立した試算で推定確率と倍率を表示。
- 架空の部費で**2万〜40万円（1万円刻み）**、年1回だけ順位予想を行えます。予想は任意で、遠征費48万円を残す必要があります。
- 的中時は購入額×確定倍率を含む合計払戻しを部費に計上。不的中では払戻しなし。オッズ算出が実レース結果を変えることはありません。
- **現実のお金・景品交換・換金・外部への送金・実在レースの賭けはありません。** 開発用ゲーム内シミュレーションです。
- **8シーズン以内に一度も全国優勝できなければGAME OVER。** 途中で優勝した場合も、残りの年度を継続して遊べます。
- ギャンブルに見える仕様には販売先による制限があるため、**販売版への搭載はストアの事前確認が必要**です。ルール詳細は [順位予想と制限](docs/PREDICTION_RULES.md) を参照してください。


**オッズ計算の更新：** 大会前に512通りのシナリオ（晴384・雨128）を本番と同じエンジンで試算し、結果をキャッシュします。出走選手・能力が変わると再計算します。予想金額は**2万円〜40万円、1万円刻みで全39種類**から選べます。1.0〜16.0倍の倍率と標本誤差区間を表示します。

## v0.5.0 大会中の有料給水と大学生活イベント

- 全5区間・15地点で**0〜3杯の給水指示**。給水支援1杯あたり部費12,000円（給水スタッフや準備・輸送をまとめたゲーム上の経費）。0杯なら無料。1杯ずつ渡すと総額180,000円。
- **脱水・飲みすぎ**の双方が走行時間に影響。過剰給水は「お腹タポタポ」ペナルティで失速。0杯に節約し続けるのも不利。水分状態と胃の負担ゲージを画面に表示。
- 育成に使わなかった部費を、大会中の給水支出に回せます。遠征費48万円を払った後の残額が給水予算になります。
- 週次育成に9種のランダムイベントを追加：主力選手に恋人ができて2週ほど練習の時間が減る／恋人の励ましで集中力向上／軽い痛み／ライバル合同練習／坂道フォーム開眼／外部の批判／栄養改革／卒業生指導／地域の支援金。選手や部費に実際に影響し、イベント履歴を確認可能。
- 難易度調整は固定500シードで検証。既存の育成方針で5年目17.8%、6年目32.4%が優勝。給水の戦術次第では能力の劣る側が勝つ可能性あり。
- 生理・体調はあくまで**ゲーム用の抽象モデル**です。実際のスポーツに必要な給水の助言には使用できません。

## Alpha v0.6.0 — 全国高校スカウト制度

- 全国**40の架空高等学校**に、毎年高校3年生の候補者が2〜3名ずつ分散（合計80〜120名程度）。
- 高校の在籍候補者・突出した能力・天才候補の学校は**訪問前には表示されない**。視察先は40校から選び、1校あたり**18万円**を部費として使う。
- 1年間の訪問上限は3校、発見した候補への**入部打診は最大3名**。見つけた選手が必ず入部するわけではなく、入部辞退の可能性もある。
- 調査した高校の卒業生が翌年度の新入生として加入した場合、元の高校と実力を引き継ぐ。スカウトをしなくても従来どおり一般入部は続く。
- 候補者の能力は視察時の概算値として見える。いわゆる「スーパー1年生」がどの高校にいるかは、ゲーム開始時点で知らされない。
- 高校名はゲーム用の架空名称。実在の学校に対応する選手、スカウト実績や出身地ではない。

## 新入部員とスーパー1年生

年度末に入る新入部員には、低確率で**特待級ルーキー**や**天才1年生**が混じります。初期能力の一部または複数が突出し、名鑑に金色の★マークを表示。通常は2.5%を基礎に、当年度のスカウト活動1回ごとに出現確率が1.2ポイント上がります。さらに例外的な天才型になる確率を設定しています。CPU大学にも確率で逸材が入部するため、自校だけが有利にはなりません。実物の選手・大学には紐付けていません。

## ゲームの仕組み

- **大学・ライバル:** 自チーム＋CPU7大学、特に「北稜大学」が強豪。各校に10人の選手名簿があり、能力育成・学年進行・卒業・新入生・区間配置・活動資金を個別管理。すべて架空名称。
- **長期育成:** 全10選手、5能力（スピード・スタミナ・登坂能力・精神力・回復力）。12週を1年分の育成として圧縮。4年生は年度末に卒業し、新入生が加わる。大学の育成基盤が成長するにつれて、後年の新入生水準も上がる。
- **人間らしい揺らぎ:** 当日の好不調・雨天・疲労・偶発的な失速・4年生の意地・レース戦術の相性を反映。ランクが低くてもまれに逆転できる。**順位や優勝を直接抽選する仕組みではない**。
- **CPU戦:** 全7大学が各区間で走行ペースを計算。北稜大学は当初圧倒的に強いが、永遠に手の届かない能力ではない。CPUが不正な補正によって自動優勝することはない。
- **レース:** 1区8km（平坦）、2区10km（上り）、3区12km（持久）、4区8km（下り）、5区12km（最終）。全15地点で「温存 / 標準 / 攻め」を選択し、体力配分を調整。
- **記録の蓄積:** 選手の8・10・12km自己ベスト、卒業生名鑑、過去8大学の全順位・総合タイム、前年度のライバル順位を記録。
- **操作ガイド:** ゲーム内「監督手帳」で育成・レース・決算の手順を確認可能。
- **買い切り向け設計:** 完全オフライン。アカウント・広告・サーバー・課金機能はなし。シミュレーションに乱数シードを使い、結果を再現可能。

## 部費と決算

財務は**架空の大学駅伝部をモデルにしたゲームバランス用の現金主義帳簿**です。実大学の監査済み予算ではありません。

| 入出金 | 初年度金額 |
| --- | ---: |
| 大学の年間部費配分 | +¥4,000,000 |
| OB・OG会の活動支援 | +¥600,000 |
| 年間運営経費（施設・保険・指導補助・用具） | −¥2,200,000 |
| 自由に配分できる期首現金 | **¥2,400,000** |
| 調整・通常・高強度練習 | −¥38,000 / −¥72,000 / −¥110,000（各週） |
| 大会遠征費 | −¥480,000（大会開始時） |
| 強化合宿 | −¥420,000（次回の選抜5人の対象能力上昇×2） |
| フォーム・乳酸測定 | −¥160,000（次回の選抜5人の対象能力上昇×1.35） |
| 抽選で届く特別合同合宿招待 | −¥260,000（期限内に参加費支払い。次回の選抜5人の成長×2） |
| 高校生のスカウト活動 | −¥180,000（1年度最大3回。次年度の新入生の初期能力を改善） |
| 栄養・リカバリー支援 | −¥150,000（疲労を減らす） |
| 雨天対応用品 | −¥240,000（次の雨大会に有効） |

- 運営経費は年度初めに**全額計上・支払い済み**。期末に二重計上しません。
- 最低限の残り練習費＋大会遠征費を支払えなくなる買い物・高強度練習はブロックされます。
- 練習後、ランダムに**期限付きの合同合宿招待枠**を獲得できることがあります。招待が当たっても自動では発動せず、部費から参加費を支払うと通常合宿より安く成長2倍を利用できます。
- 大会の好成績後にOB・OG会から活動支援の追加収入があります（賞金ではありません）。
- 収入・支出は購入や練習のたびに1件ずつ記帳。年度決算で収入・支出・収支・期末現金を保存。
- 次年度に現金を繰り越し。過去年度の明細もUIから確認できます。
