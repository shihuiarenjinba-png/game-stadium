# EKIDEN MANAGER — 栄光への襷

**ローカル・オフラインで動作する、大学駅伝育成＆部費経営シミュレーション（Alpha v0.3）**

架空の大学駅伝チームの監督として、選手の5つの能力を育てながら、区間配置とレース戦略、年間の部費を管理します。CPU7大学との5区間・50kmレース（各区間を3分割した全15チェックポイント）で、絶対王者「北稜大学」の連覇を止めることが目標です。運と精神面も結果に影響するため、能力値の大小だけでは順位が決まりません。

> **開発途中の試作版です。** Windows向けの未署名テストEXEは生成できますが、販売用決済・ライセンス認証、コード署名、外部テスターによる品質保証は未完了です。大学・大会・選手・資金は架空の設定です。

## 遊び方（ネット回線・サーバー不要）

1. リポジトリをZIPで取得して展開する。
2. Windowsで `index.html` をダブルクリックしてブラウザー（Edge/Chrome等）で開く。
3. 「区間配置」で5人を選び、「週間トレーニング」で12週分の育成を進める。
   - スカウト活動（1回18万円・年3回まで）に投資すると、翌年度の新入生の能力が上がります。
4. 部費を使い、強化合宿や栄養・リカバリー支援などを購入する。
5. 「大会を開始する」→ 1区間3地点×5区間の計15チェックポイントでペース（温存・標準・攻め）を指示 → 結果を確認する。残体力が少ない状態で攻めすぎると失速します。
6. 「年度決算を確定して次年度へ」で、卒業・新入部員加入の次年度に進む。

**セーブ:** ブラウザーの `localStorage` に自動保存を試みます。ローカルファイル（`file://`）のストレージ挙動はブラウザーによって異なるため、必ず画面下の「セーブ書き出し」でJSONバックアップを保管してください。「セーブ読込」で続きを再開できます。

## ゲームの仕組み

- **大学・ライバル:** 自チーム＋CPU7大学、特に「北稜大学」が強豪。各校に10人の選手名簿があり、能力育成・学年進行・卒業・新入生・区間配置・活動資金を個別管理。すべて架空名称。
- **長期育成:** 全10選手、5能力（スピード・スタミナ・登坂能力・精神力・回復力）。12週を1年分の育成として圧縮。4年生は年度末に卒業し、新入生が加わる。大学の育成基盤が成長するにつれて、後年の新入生水準も上がる。
- **人間らしい揺らぎ:** 当日の好不調・雨天・疲労・偶発的な失速・4年生の意地・レース戦術の相性を反映。ランクが低くてもまれに逆転できる。**順位や優勝を直接抽選する仕組みではない**。
- **CPU戦:** 全7大学が各区間で走行ペースを計算。北稜大学は当初圧倒的に強いが、永遠に手の届かない能力ではない。CPUが不正な補正によって自動優勝することはない。
- **レース:** 1区8km（平坦）、2区10km（上り）、3区12km（持久）、4区8km（下り）、5区12km（最終）。全15地点で「温存 / 標準 / 攻め」を選択し、体力配分を調整。
- **記録の蓄積:** 選手の8・10・12km自己ベスト、卒業生名鑑、過去8大学の全順位・総合タイム、前年度のライバル順位を記録。
- **操作ガイド:** ゲーム内「監督手帳」で育成・レース・決算の手順を確認可能。
- **買い切り向け設計:** 完全オフライン。アカウント・広告・サーバー・課金機能はなし。シミュレーションに乱数シードを使い、結果を再現可能。

## 部費と決算

財務は**架空の大学駅伝部をモデルにしたゲームバランス用の現金主義帳簿**です。実大学の監査済み予算ではありません。

| 入出金 | 初年度金額 |
| --- | ---: |
| 大学の年間部費配分 | +¥4,000,000 |
| OB・OG会の活動支援 | +¥600,000 |
| 年間運営経費（施設・保険・指導補助・用具） | −¥2,200,000 |
| 自由に配分できる期首現金 | **¥2,400,000** |
| 調整・通常・高強度練習 | −¥38,000 / −¥72,000 / −¥110,000（各週） |
| 大会遠征費 | −¥480,000（大会開始時） |
| 強化合宿 | −¥420,000（次回の選抜5人の対象能力上昇×2） |
| フォーム・乳酸測定 | −¥160,000（次回の選抜5人の対象能力上昇×1.35） |
| 抽選で届く特別合同合宿招待 | −¥260,000（期限内に参加費支払い。次回の選抜5人の成長×2） |
| 高校生のスカウト活動 | −¥180,000（1年度最大3回。次年度の新入生の初期能力を改善） |
| 栄養・リカバリー支援 | −¥150,000（疲労を減らす） |
| 雨天対応用品 | −¥240,000（次の雨大会に有効） |

- 運営経費は年度初めに**全額計上・支払い済み**。期末に二重計上しません。
- 最低限の残り練習費＋大会遠征費を支払えなくなる買い物・高強度練習はブロックされます。
- 練習後、ランダムに**期限付きの合同合宿招待枠**を獲得できることがあります。招待が当たっても自動では発動せず、部費から参加費を支払うと通常合宿より安く成長2倍を利用できます。
- 大会の好成績後にOB・OG会から活動支援の追加収入があります（賞金ではありません）。
- 収入・支出は購入や練習のたびに1件ずつ記帳。年度決算で収入・支出・収支・期末現金を保存。
- 次年度に現金を繰り越し。過去年度の明細もUIから確認できます。

## ソース構成

## テスト

Node.js 20以上がある場合：

```sh
npm test
```

パッケージの追加インストールは不要です（標準ライブラリのみ）。GitHub Actionsでもテストが走る設定です。

## Windows用の開発ビルド

開発ブランチの [Windows desktop unsigned alpha（GitHub Actions）](https://github.com/shihuiarenjinba-png/game-stadium/actions/workflows/windows-build.yml) を開き、成功した最新の実行履歴の下にある Artifacts から `ekiden-manager-windows-UNSIGNED-alpha` を取得して展開できます。アーカイブにはPortable版およびインストーラー版のEXEが含まれます。**Windows x64用の未署名・テスト版であり、販売用の完成品ではありません。** Windowsのセキュリティ警告が出る可能性があります。安全性確認なしに警告を無視するよう促すものではありません。

リポジトリをZIPで取得するだけなら、Node.js・Pythonをインストールせず `index.html` からブラウザー版を試せます。デスクトップアプリのEXE生成にはGitHub ActionsまたはNode.js 22・Python 3の開発環境が必要です。
